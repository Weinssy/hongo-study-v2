# Fase 5 Hongo Study v2: Rilis (Bagian Lokal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Menyelesaikan bagian Fase 5 yang bisa dikerjakan lokal: halaman /tentang, halaman utama dan README yang mencerminkan v2 lengkap, polesan responsif dari kode, berkas pengumuman siap tempel untuk situs lama, dan paket naskah Papercut peluncuran. Tanpa push, tanpa deploy, tanpa render, tanpa jadwal.

**Architecture:** Tidak ada modul baru. Perubahan berupa halaman statis /tentang, penulisan ulang copy halaman utama agar sesuai fitur yang benar-benar ada, penyesuaian CSS responsif, dan berkas dokumen di `docs/` serta paket episode Papercut di luar repo.

**Tech Stack:** Next.js App Router, CSS yang ada, Markdown/HTML dokumen.

**Spec:** Outline Fase 5. Bagian yang memang bukan pekerjaan lokal (pengumuman benar-benar ditempel di repo lama, konten dijadwalkan lewat Buffer) disiapkan berkasnya dan dicatat sebagai langkah Wein di laporan.

## Global Constraints

- Batasan semua fase tetap berlaku.
- Copy baru harus sesuai fitur nyata (R-38): tidak ada klaim fitur yang belum dibangun, tidak ada statistik tanpa sumber (R-17), tanpa em dash (R-02), tanpa kata generik pemasaran (R-16).
- CTA harus spesifik konteks (R-15): "Mulai sesi belajar", bukan ajakan umum.

## Design Read dan alasan keputusan (R-31)

Bahasa visual sama sejak Fase 2 (buku catatan, kertas hangat, merah aka), dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- Halaman utama disusun mengikuti alur pakai nyata (belajar, kuis, progres), bukan templat hero + grid fitur generik (R-05, C-3).
- Radius CTA utama disamakan 10px dengan seluruh sistem tombol Fase 2 (R-11): pil hanya dipertahankan untuk chip filter yang memang label.
- Header di HP: nav boleh membungkus ke baris kedua; tidak ada menu hamburger karena hanya 6 tautan dan semuanya muat (keputusan dicatat, bisa ditinjau ulang bila nav bertambah).

## Review Focus

- Semua tautan di halaman utama, /tentang, dan nav menunjuk halaman yang ada (R-24).
- Berkas pengumuman situs lama berdiri sendiri (HTML + CSS sebaris) karena ditempel ke situs statis lama yang tidak berbagi stylesheet dengan v2.
- Naskah Papercut mengikuti pola episode 03: script.json berisi 10 baris ber-id l1_hook sampai l10_cta, 75 sampai 95 kata total.
